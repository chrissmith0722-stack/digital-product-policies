# digital-product-policies

Starter **refund**, **delivery**, and **terms** templates for sellers of digital goods (downloads, templates, Notion packs, ebooks).

## Files

| File | Use |
|------|-----|
| `REFUND_POLICY.md` | Storefront refund / no-refund language |
| `DELIVERY_POLICY.md` | How and when files are delivered |
| `TERMS_OF_USE.md` | License / acceptable use for buyers |

## How to use

1. Copy into Gumroad, Etsy, Stripe payment page, or your site footer.
2. Replace `{{business_name}}`, `{{support_email}}`, and jurisdiction placeholders.
3. Have a lawyer review before relying on these for compliance — these are **templates, not legal advice**.
